# Task 8: Working with VPNs

### Objective
To understand how VPNs protect online privacy and encrypt network communication.

### Steps
1. Signed up for ProtonVPN Free.
2. Installed and connected to Netherlands server.
3. Verified IP change using whatismyipaddress.com.
4. Tested encrypted browsing.
5. Compared IP and speed before & after disconnection.

### Tools
- ProtonVPN (Free)
- Microsoft Edge

### Outcome
- Successfully changed IP address and encrypted data traffic.
- Gained hands-on knowledge of VPN working, encryption, and tunneling.
